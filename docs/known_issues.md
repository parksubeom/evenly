## 기획서 생성 쪽에서 남은 것

- 작업 요청서의 "12장 HBI 정의"는 현재 번호로 **15장**(핵심 지표)입니다. 12장은 전처리 파이프라인이라 15장에 반영했습니다.
- 13장(분석 프레임워크) 도구 문구와 부록 2·3(기술 스택·코드 예시)은 `geopandas·rasterio·networkx` 기준으로 쓰여 있으나,
  실제 v4 는 QGIS 내장 Python(numpy + GDAL)과 자체 Dijkstra 입니다. 이번 범위 밖이라 두었고, 제출 전 문구 통일을 권장합니다.
- 9장·부록1 의 DEM 기간은 "2024.11 (2021 기준)"으로 적었습니다. 제공 명세의 제작 기준연도를 한 번 더 확인하세요.
- 23장 공익 효과(연간 절감 분)는 가정을 여럿 얹은 **상한 추정**입니다. 가정은 슬라이드 각주에 자동으로 붙습니다.
- 렌더 확인은 LibreOffice(맑은 고딕 대신 Apple SD Gothic Neo)로 했습니다. PowerPoint·맑은 고딕에서 글자 폭이 조금 다를 수 있어 제출 전 PowerPoint로 한 번 열어 보세요.
