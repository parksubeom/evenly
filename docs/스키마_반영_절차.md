# 화요일 스키마 반영 절차 (schema.txt·runlog 받은 날)

목표: **화요일 저녁 v6 번들 메일 반입.** 월요일 밤까지 스키마 말고는 다 끝내 두고, 화요일에는 아래 순서만 한다.

## 받을 것

- `schema.txt`: 1차 방문 때 반출 신청한 ogrinfo 결과 (레이어·칸 이름·형식·객체 수)
- `runlog`: v5 실행 화면 (단계별 시각 → 걸린 시간, 02 연결망 개수·노드 비율, 03 "주거 0개" 등)
- 담당자 답: **건물 속성 판(BPRP_SE·BULD_SE·BFLR_CO 가 있는 건물 레이어)이 따로 있는가**
