## 결과 받은 날 할 일 (반출 파일 수령 → 완성본까지)
1. 반출 파일 전부 `results/raw_export/` 에 넣고 위 체크리스트로 빠진 파일 확인
2. `cd results/raw_export && python3 ../../analysis/hbi/tools/outside_elderly.py dong_hbi.csv 인구파일.csv` (고령인구 추정표)
3. `deck/inputs.json` 에 팀명·방문일 5개 입력
4. `cd deck && npm run build:real` → `deck/data/missing.txt` 의 "누락" 줄이 없어질 때까지 파일 보충 후 재실행
5. `python3 tools/check_deck.py deliverables/언덕위우리동네_기획서_final.pptx` 통과 확인 → PowerPoint로 열어 훑어보기 → `python3 demo/build_demo.py` 로 데모도 갱신
