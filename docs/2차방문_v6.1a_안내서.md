# 2차 방문 v6.1a 따라하기 (안심구역 · 관악만 분석하는 날)

**컬러로 인쇄하세요** (검은 입력 상자·빨간 번호·초록/빨강 칸을 색으로 구분합니다).

**어느 안내서를 쓰나**: 작업 폴더에 **`hbi_code_bundle_v6.1a.txt`** 가 있으면 이 안내서. v6.1a 는 자료가 어떻게 생겼든 **코드를 고치지 않고** 맞춥니다. **자료 맨 위 폴더 하나만** 알려 주면 `setup` 이 나머지를 찾습니다.

**오늘은 관악만 분석하는 날**: 지금 받은 수치지형도·DEM 은 **관악구 11도엽뿐**입니다 (나머지 4개 구는 메일로 요청함). setup 이 `자료가 덮는 대상 구: 관악구. 이 구만 분석할까요?` 를 물으면 **Enter**. 그러면 결과는 관악구만 나오고, 선정지 5곳 중 **봉천동 1곳**만 계산됩니다 (정상). 화면·결과 파일에 `대상 5개 구 중 1개 구만 자료 있음` 이 남습니다. 관악(11도엽) 밖의 구간·시설·등시선 점은 화면에 `→ 길 자료 범위 밖으로 보고 건너뜀` 이 붙은 줄이 나오고 결과에 줄이 생기지 않습니다. 관악 밖 선정지는 결과에 건물 0 인 빈 줄로 남습니다 (모두 정상). 나머지 구 자료가 들어오면 setup 부터 다시 하면 원래 5개 구로 돌아갑니다.

**읽는 법 — 무엇을 입력하나**
- **"입력" 이 붙은 검은 상자 안의 글자만** 명령창에 그대로 칩니다. 위의 "하는 일" 은 설명이라 치지 않습니다.
- 문장이나 표 속의 `$ python check.py` 처럼 **검은 칸**도 입력할 명령입니다. **회색 칸**은 화면이나 파일에서 찾아볼 글자라 치지 않습니다.
- 안심구역 PC 의 자료·번들 폴더는 매번 **`C:\Users\user\Desktop\박수범`** 입니다 (안내서의 명령은 모두 이 주소 기준). 그림 속 빨간 번호 ①②③ 은 그 장의 글에서 "그림 ①" 처럼 가리키는 곳입니다.

| 순서 | 할 일 | 입력 |
|---|---|---|
| 단계 0~2 | 준비 → 명령창 → 번들 풀기 | `$ python hbi_code_bundle_v6.1a.txt` |
| 단계 3 | 준비 도우미: 자료를 찾아 설정을 채움 (질문에는 **Enter**, 관악만 분석할지도 Enter) | `$ python setup.py` |
| 단계 4 | 출발 전 점검 (멈추면 질문에 Enter 하거나 mapping.txt 몇 줄 고치기) | `$ python check.py` |

2. 입력 상자 속 명령은 검은 창에 **그대로 타자로 치고 Enter**. 맨 아래에 `C:\Users\user\Desktop\박수범>` 처럼 **폴더 주소와 `>`** 가 다시 나타나야 다음 명령을 칩니다.

## 단계 4. 출발 전 점검 (check)

할 일: 분석 전에 자료가 말이 되는지 봅니다 (몇 분). **맨 아래 `=== 결과 ===` 만 먼저 봅니다.**

1. 아래 상자를 칩니다.

5. 그림 ⑤ 관악구의 주거 비율과 `주거→길 연결` 을 메모 칸에 적습니다.
