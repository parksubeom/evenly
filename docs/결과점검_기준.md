## 건물 용도 자동 선택 (`building_attr_mode = auto`)

`check.py` 가 대상 구마다 1km 표본 창에서 **layer → register → gisbld → all** 순서로 잰다.

| 방식 | 연결률의 뜻 | 쓸 수 있는 조건 |
|---|---|---|
| layer | 건물 레이어 용도 칸에 값이 있는 건물 비율 | 건물에 용도 칸(BPRP_SE 등)이 있음 |
| register | 건물 → 필지 → 건축물대장으로 용도가 붙은 비율 (`register_join`: pnu 기본) | 건축물대장 파일 + 필지 |
| gisbld | 건물 면적의 30% 이상 겹치는 GIS 건물이 있는 비율 | `external/gis_building.gpkg` |
| all | (항상 씀, 용도 미구분) | |

**처음으로 80% 이상인 방식**을 고르고, 고른 방식과 이유를 화면·`check_report.txt`·`mapping.txt` 의 `building_attr_chosen` 줄에 적는다. 80% 근거: 결과 점검표의 용도 연결률 초록 기준과 같게 맞춤. 대장 pnu 채움률(99.96%)과 비교해 80% 아래면 결합 방식 자체가 맞지 않는 경우가 대부분이라 다음 방식으로 넘어감.

gisbld 의 30% 겹침 기준: 같은 건물이면 도형이 조금 어긋나도 대부분 겹치고(가짜 자료 시험의 평균 겹침률 83%), 이웃 건물과 맞닿은 조각 겹침(몇 %)으로 남의 용도를 붙이지 않게 함.
