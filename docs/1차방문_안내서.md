# 1차 방문 안내서 (안심구역 · v4)

1차 방문 날 안심구역 컴퓨터에서 할 일을 **이 문서 하나**에 모았습니다. 예전 문서 넷(상세판·따라하기판·그림안내·맥 리허설)은 이 문서로 합쳤고, 원본은 `docs/archive/` 에 보관합니다.

| 부 | 누가 보나 | 내용 |
|---|---|---|
| **1부 한 장 요약** | 명령창이 익숙한 사람 | 전체 순서와 명령을 한 장에 |
| **2부 따라 하기** | 처음 해 보는 사람 | 한 장에 한 단계 (단계 0 ~ 8). 화면 그림과 "성공하면/이상하면" |
| **3부 자세한 설명** | 왜 이렇게 하는지 궁금할 때, 결과를 받은 뒤 | 구역을 나누는 이유, 확인 기준, 반출 규칙, 밖에서 합치는 법 |
| **4부 부록: 맥 리허설** | 방문 전에 연습할 사람 | 이 맥에서 가짜 데이터로 똑같이 해 보기 |

**꼭 지킬 것 세 가지**
- 구역(A·B·C·D)마다 `AREA_BBOX` 한 줄만 바꾸고 `python run_all.py` 한 줄로 돌립니다.
- `EDGE_BUFFER` 는 바꾸지 않습니다 (500 그대로).
- `output_A` ~ `output_D` 만 반출합니다. `work` 폴더는 반출하지 않습니다.

## 1부. 한 장 요약

**흐름: ① 준비(한 번) → ② 구역 A·B·C·D 네 번 → ③ 반출.** v4 코드는 서로 이어진 길 묶음 가운데 가장 큰 하나만 계산하므로, 떨어진 네 동네 묶음을 분석 범위(`AREA_BBOX`)를 바꿔 가며 따로 돌립니다.

| 순서 | 할 일 | 명령 / 바꿀 줄 |
|---|---|---|
| ① 준비 1 | 담당자에게 폴더 4개 주소 받기: 수치지형도, DEM 5m, 국토정보필지(없으면 생략), 작업 폴더 | |
| ① 준비 2 | 시작 메뉴 → **OSGeo4W Shell** 열기 | |
| ① 준비 3 | 번들 풀기 | `cd /d D:\작업폴더` → `python hbi_code_bundle_v4.txt` → `cd hbi` |
| ① 준비 4 | 설정 파일에 주소 3개 (`r"…"` 의 `r` 은 그대로) | `notepad config.py` → `DATA_ROOT_MAP`, `DATA_ROOT_DEM`, `DATA_ROOT_PARCEL` |
| ① 준비 5 | 자료 점검: `shp 파일 총 N개` 0 아님, `[있음] sidewalk_cl·road_cl·building`, 지목 한글 | `python 01_inspect.py` |
| ② 구역마다 1 | `AREA_BBOX` 줄을 아래 표의 그 구역 줄로 바꾸고 저장 | `notepad config.py` |
| ② 구역마다 2 | 분석 (01·02·03·04·05·06 순서로 나옴. 06 은 필지가 있을 때만) | `python run_all.py` |
| ② 구역마다 3 | 메모: 02 `최대 연결망 노드 비율` (90% 이상), 03 `데이터 경계 500m 이내 …(x%)` (100% 아님) | |
| ② 구역마다 4 | 결과 폴더 이름 바꾸기 | `ren output output_A` (B·C·D) |
| ③ 마무리 | `AREA_BBOX = None` 으로 되돌리기, `output_A`~`D` 반출 신청 (`work` 는 반출 안 함) | `notepad config.py` |

| 구역 | 동네 | 메모장에 넣을 줄 |
|---|---|---|
| A□ | 종로구·중구 | `AREA_BBOX = [194500, 548300, 203400, 560200]` |
| B□ | 관악구 | `AREA_BBOX = [190100, 536300, 200000, 545000]` |
| C□ | 광진구 | `AREA_BBOX = [203900, 546100, 211100, 553700]` |
| D□ | 강서구 | `AREA_BBOX = [178200, 546400, 190500, 557200]` |

**멈춤 규칙**: `!! … 에서 중단` 이 나오면 2부 단계 8 의 표대로 합니다. 표대로 해도 안 되면 그 구역은 `ren output output_A_실패` 하고 다음 구역으로 갑니다. 표에 없는 오류이면 멈추고, 오류 마지막 줄을 적어 옵니다.

# 2부. 따라 하기 (처음 해 보는 사람용)

한 장에 한 단계씩입니다. 장마다 맨 위에 "단계 0" ~ "단계 8" 이름이 있습니다(단계 5 는 두 장: 5, 5-2). 장마다 "할 일 → 따라 하기 → 화면 예시 → 성공하면/이상하면" 순서로 읽습니다.
그림 속 빨간 번호 ①②③ 은 그 장의 글에서 "그림 ①" 처럼 가리키는 곳입니다. 상자 속 명령은 **글자·띄어쓰기·기호까지 똑같이** 칩니다. 단 하나, `D:\작업폴더` 자리에는 단계 0 ④ 에 적은 주소를 칩니다.

## 단계 0. 준비물과 물어볼 것

할 일: 가져갈 것을 챙기고, 담당자에게 폴더 네 곳의 주소를 받아 적습니다.

1. 챙길 것: 신분증, 이 안내서, 펜
2. 안심구역 담당자에게 아래 네 가지를 묻고, 오른쪽 칸에 **주소(폴더 위치)를 그대로** 적습니다.

| 물어볼 것 | 받아 적을 주소 |
|---|---|
| ① 수치지형도 폴더 (지도 파일이 있는 곳) | |
| ② DEM 5m 폴더 (높이 자료가 있는 곳) | |
| ③ 국토정보필지 폴더 (서울 필지. 못 받으면 "없음") | |
| ④ 작업 폴더 (우리 파일 `hbi_code_bundle_v4.txt` 를 둘 곳) | |

| 성공하면 | 이상하면 |
|---|---|
| 네 칸이 모두 채워짐 (③은 "없음"이어도 됨) | 주소를 모르겠다고 하면: "파일 탐색기에서 그 폴더를 열어 주세요"라고 부탁하고, 단계 3의 방법으로 주소를 복사 |

이 안내서에 나오는 낱말:
- **필지**: 땅 한 조각(지적도의 한 칸). **DEM**: 땅의 높이를 담은 자료. **shp**: 지도 파일의 한 종류
- **sidewalk_cl · road_cl · building** 같은 영어: 지도 파일 이름 (보도·도로·건물 등). 뜻을 몰라도 화면에서 글자만 맞춰 보면 됩니다
- **반출(반출 신청)**: 안심구역 안에서 만든 결과를 밖으로 가지고 나가겠다고 신청하는 것. 담당자가 확인한 뒤 내보내 줍니다
- **번들**: 우리 분석 파일을 한 파일로 묶은 것 (`hbi_code_bundle_v4.txt`). **AREA_BBOX**: 분석 범위(계산할 지역)를 정하는 설정 줄
- **연결망 노드 비율**: 길이 끊기지 않고 한 덩어리로 이어진 정도. **데이터 경계**: 받은 지도 자료의 가장자리
- **PARCEL_ENCODING · CP949 · UTF-8**: 한글 글자를 읽는 방식 설정. 글자가 깨질 때만 바꿉니다. 그 밖의 영어(좌표계 prj 등)는 몰라도 됩니다
- **파일 탐색기**: 폴더 창. 키보드의 **윈도 키 + E** 를 함께 누르면 열립니다

## 단계 1. 명령창 열기

할 일: 명령창(글자로 컴퓨터에 지시하는 검은 창)을 엽니다.

1. 화면 왼쪽 아래 **시작 단추**를 클릭합니다.
2. 키보드로 `OSGeo4W` 를 칩니다.
3. 목록에 나온 **OSGeo4W Shell** 을 클릭합니다(그림 ①). 검은 창이 뜹니다.
4. 이 안내서의 굵은 테두리 상자 속 명령은 검은 창에 **그대로 타자로 치고 Enter** 를 누릅니다. 다른 곳에서 글자를 복사해 왔다면, 검은 창 안에서 **마우스 오른쪽 클릭** 또는 **Ctrl+V** 로 붙여 넣을 수 있습니다.

```screen start
OSGeo4W
⟦1⟧OSGeo4W Shell⟦/⟧
```

명령이 끝나면 맨 아래에 `D:\작업폴더>` 처럼 **폴더 주소와 `>`** 가 다시 나타납니다 (단계 2 그림 ③ 에서 볼 수 있음). 이것이 "다음 명령을 쳐도 된다"는 신호입니다. 그 전에는 다음 명령을 치지 않습니다.

| 성공하면 | 이상하면 |
|---|---|
| 검은 창이 뜨고, 맨 위 제목에 "OSGeo4W Shell" 이라고 쓰여 있음 | 목록에 없으면 담당자에게 "QGIS 의 OSGeo4W Shell 이 어디 있나요?"라고 묻기. **실행 중에는 검은 창을 닫지 않습니다** |

## 단계 3. 설정 파일에 폴더 주소 넣기

할 일: 메모장으로 설정 파일(`config.py`)을 열어, 단계 0에 적은 폴더 주소 ①②③ 세 개를 넣습니다 (④는 단계 2에서 이미 씀).

1. 아래 상자를 치고 Enter. 메모장이 열립니다.
2. **Ctrl+F** → `DATA_ROOT_MAP` 을 쳐서 그 줄을 찾습니다.
3. 따옴표 `"` 안의 글자만 지우고 단계 0 ① 주소를 넣습니다(그림 ①). **따옴표 앞의 `r` 과 따옴표 두 개는 지우지 않습니다.** 같은 방법으로 `DATA_ROOT_DEM` 에 단계 0 ② 주소를 넣습니다(그림 ②). `DATA_ROOT_PARCEL` 은 처음에 `None` 이라 따옴표가 없습니다: `None` 을 지우고 그림 ③ 처럼 `r"단계 0 ③ 주소"` 를 씁니다. ③이 "없음"이면 `None` 그대로 둡니다. 다른 줄(`DATA_ROOT_DEM1M`, `EDGE_BUFFER` 등)과 `#` 뒤 설명 글은 건드리지 않습니다.
4. **Ctrl+S** 로 저장합니다. 메모장은 닫아도 됩니다.

```
notepad config.py
```

```screen notepad 바꾸기 전
DATA_ROOT_MAP = r"D:\data\수치지형도"     # ★ 수치지형도 .shp 파일들이 있는 폴더
DATA_ROOT_DEM = r"D:\data\DEM5m"          # ★ DEM 5m .img 파일들이 있는 폴더
…
DATA_ROOT_PARCEL = None                    #   국토정보필지 폴더 (2회차에 승인되면 경로 입력)
```

```screen notepad 바꾼 후 (주소는 예시)
DATA_ROOT_MAP = ⟦1⟧r"E:\제공자료\수치지형도"⟦/⟧     # ★ 수치지형도 .shp 파일들이 있는 폴더
DATA_ROOT_DEM = ⟦2⟧r"E:\제공자료\DEM5m"⟦/⟧          # ★ DEM 5m .img 파일들이 있는 폴더

```

주소 복사하기: 파일 탐색기에서 그 폴더를 열고 **주소창 빈 곳을 클릭** → 주소가 파랗게 선택됨 → **Ctrl+C** → 메모장 따옴표 안에서 **Ctrl+V** (그림 ④).

```screen explorer E:\제공자료\수치지형도
⟦4⟧E:\제공자료\수치지형도⟦/⟧
```

| 성공하면 | 이상하면 |
|---|---|
| 세 줄의 따옴표 안이 받아 적은 주소로 바뀌고 저장됨 | `r` 이나 따옴표를 지웠으면 그림처럼 `r"…"` 로 되돌림. 저장을 잊으면 단계 4에서 `shp 파일 총 0개` 가 나옴 |

| 화면 문구 | 뜻 → 할 일 |
|---|---|
| `[없음] building`, 또는 `sidewalk_cl`·`road_cl` **둘 다** [없음] | **분석 불가**: 집 또는 길 지도가 없음 → 멈추고 담당자에게 파일 이름 확인 |
| `sidewalk_cl`·`road_cl` 중 **하나만** [없음], 또는 `[없음] stairs` · `bus_stop` · `station` | **결과 약화**: 길 일부·계단·정류장·역이 빠짐 → 메모하고 계속 |
| `[없음] bridge` · `tunnel` · `overpass` | **괜찮음**: 다리·터널·육교 → 그대로 계속 |

| 성공하면 | 이상하면 |
|---|---|

# 3부. 자세한 설명

### 왜 구역을 넷으로 나눠 돌리나
v4 분석 코드는 **길 연결망 가운데 가장 큰 덩어리 하나만** 남깁니다(`lib/qnetwork.py` ⑧). 5개 구는 서로 떨어진 네 묶음(종로·중 / 관악 / 광진 / 강서)이라, 한 번에 돌리면 한 묶음만 남고 나머지 구의 집은 통째로 빠집니다. 공개 도보 네트워크로 재 보면 가장 큰 덩어리만 남길 때 노드의 38.2%만 남습니다. v4 코드는 반입 심의를 받은 그대로라 고칠 수 없으니, **config.py 의 `AREA_BBOX` 만 바꿔 구역마다 따로 돌립니다** (v5 에서는 코드로 고침).

### 구역별 분석 범위 (EPSG:5186, 대상 구 범위 + 1,000m, 100m 단위로 바깥쪽 반올림)

| 구역 | 대상 구 | config.py 에 넣을 줄 | 크기 | 들어 있는 선정지 (잘린 선까지 거리) |
|---|---|---|---|---|
| A | 종로구·중구 | `AREA_BBOX = [194500, 548300, 203400, 560200]` | 8.9 × 11.9 km | 숭인동(2,068m), 신당동(1,949m), 대현산배수지공원 구간 |
| B | 관악구 | `AREA_BBOX = [190100, 536300, 200000, 545000]` | 9.9 × 8.7 km | 봉천동(2,631m) |
| C | 광진구 | `AREA_BBOX = [203900, 546100, 211100, 553700]` | 7.2 × 7.6 km | 중곡동 무지개계단(1,881m) |
| D | 강서구 | `AREA_BBOX = [178200, 546400, 190500, 557200]` | 12.3 × 10.8 km | 화곡동(2,786m) |

- 1,000m 를 넓힌 이유: 구 경계 너머의 병원·정류장까지 경로에 들어가게 하려고.
- v4 는 bbox 밖을 "데이터 없음"으로 보고, 잘린 선에서 500m(`EDGE_BUFFER`) 안의 건물을 통계에서 자동으로 뺍니다(`lib/qedge.py`). 그래서 대상 구 안 건물은 잘린 선에서 1,000m 이상 떨어져 있어 빠지지 않고, 선정지 반경 300m 원도 잘린 선에서 모두 1,800m 이상입니다.
- 넓힌 띠(대상 구 밖) 건물 일부는 결과에 들어가지만, 밖에서 `tools/merge_exports.py` 가 **대상 구 안 격자·동만** 남겨 합칩니다. 구역 bbox 끼리는 겹치지 않습니다 (A 는 x 203,400 까지, C 는 203,900 부터).

### run_all.py 가 하는 일
- `python run_all.py` 는 01 → 02 → 03 → 04 → 05 를 차례로 돌리고, `DATA_ROOT_PARCEL` 에 필지 경로가 있으면 06 을, SKT·KCB 경로(`JOIN_DATA`)가 있으면 07 을 이어서 돌립니다. 민감도 분석(08)은 `--sens` 를 붙일 때만 들어가므로, 시간이 되면 이름 바꾸기 전에 `python 08_sensitivity.py` 를 따로 칩니다.
- 한 단계에서 오류가 나면 거기서 멈추고 `!! <단계>.py 에서 중단. 위 오류 메시지를 확인하세요.` 가 나옵니다 (리허설에서 확인).
- 5줄(02·03·06·04·05)로 따로 돌린 것과 결과가 같습니다: 리허설에서 output CSV·PNG 11개 md5 동일, gpkg 3개는 저장 시각만 다름. 06 은 04·05 결과를 바꾸지 않아서 마지막에 돌아도 됩니다.
- **중간에 멈췄을 때**: 원인을 고친 뒤 멈춘 단계부터 한 줄씩 다시 칠 수 있습니다 (앞 단계 결과는 `work` 폴더에 남아 있음). 순서: `python 02_network.py` → `python 03_hbi.py` → `python 04_validate.py` → `python 05_export.py` → (필지가 있으면) `python 06_parcel.py`. 단 `AREA_BBOX` 나 데이터 경로를 고쳤으면 02 부터(또는 `python run_all.py` 로 처음부터) 다시.

| 05 | `완료 → output/ (반출 신청 대상)` | 이 줄이 있어야 성공 |
| 06 | `필지 N개`, `그중 지목 '대' 필지 수` | 0 이 아님. `지목 '대' 필지가 0개입니다` 면 PARCEL_ENCODING 을 `"CP949"` 로 |

- 04 의 선정지·구간은 5곳·전 구간을 구역마다 계산해도 됩니다 (합칠 때 그 구역 것만 씀). 06 은 그 구역 건물 범위 안의 필지만 읽습니다.
- 05 가 `min() iterable argument is empty` 로 멈추면 그 구역의 계산할 집이 0채입니다 (v4·v5 공통, 코드는 고치지 않음 → `docs/known_issues.md`). 멈추기 전까지 `output` 에는 04 결과 일부만 남으므로 `output_A_실패` 처럼 이름을 바꿔 두고 반출하지 않습니다.

### 반출 규칙
- `output_A`, `output_B`, `output_C`, `output_D` 네 폴더만 반출 신청합니다 (모두 격자·행정동 집계, 건물 5개 미만 제외 — v4 반출 규칙 그대로).
- `work` 는 건물 하나하나의 결과라 반출하지 않습니다. 실패한 구역 폴더(`output_?_실패`)도 반출하지 않습니다.
- 네 구역을 다 돌린 뒤 `AREA_BBOX = None` 으로 되돌려 둡니다.

### 결과를 받은 뒤 (안심구역 밖, 이 맥에서)

합칠 때 무엇을 어떻게 근사했는지는 `results/raw_export/merge_notes.txt` 에 적힙니다.
- summary 는 대상 구 격자로 다시 셉니다. 건물 5개 미만 격자는 원래 반출에 없으므로 그만큼 적게 셉니다. 중앙값은 합칠 수 없어 빠집니다.
- 선정지 백분위와 신규 후보는 합친 격자 전체 기준으로 다시 계산합니다.
