목요일 안심구역(Windows, QGIS 3.32)에서 할 일을 이 맥에서 가짜 데이터로 똑같이 해 봅니다.
쓰는 번들은 **v4** (`deliverables/hbi_code_bundle_v4.txt`, 목요일에 반입한 그 파일)입니다.
순서는 `docs/1차방문_구역별실행.md` 와 같습니다: **01 → 02 → 03 → 06 → 04 → 05**, 그다음 output 이름 바꾸기, bbox 바꿔 한 번 더.

- 아래 회색 칸의 명령을 **한 줄씩** 복사해 터미널에 붙여 넣고 Enter 를 누릅니다.
- 처음부터 끝까지 이 문서대로 해 본 결과 (2026-09-29, 이 맥): 모든 명령이 그대로 됐고 Traceback 0. 명령 실행 시간 합계 **14초** (번들 풀기부터 output_B 까지). 붙여 넣기·config 편집·화면 확인에 드는 사람 시간은 재지 못했습니다 (처음이면 20~30분 잡으세요)

## 1. 터미널 열기와 QGIS Python 준비

1. `Command + Space` → `터미널` 입력 → Enter
2. 아래 두 줄을 붙여 넣습니다. 이 맥의 QGIS 는 4.2.3이고, 그 안의 Python 경로는 `/Applications/QGIS-final-4_2_3.app/Contents/MacOS/python3.12` 입니다.
   그냥 실행하면 라이브러리를 못 찾으므로, 필요한 설정을 붙여 `python` 이라는 이름으로 부르게 합니다. 그러면 안심구역과 똑같이 `python 01_inspect.py` 처럼 칠 수 있습니다.

```
Q=/Applications/QGIS-final-4_2_3.app/Contents
```
```
python() { PYTHONHOME=$Q/Resources PYTHONPATH=$Q/Resources/python3.12:$Q/Resources/python3.12/lib-dynload:$Q/Resources/python3.12/site-packages GDAL_DATA=$Q/Resources/qgis/gdal PROJ_DATA=$Q/Resources/qgis/proj $Q/MacOS/python3.12 "$@"; }
```

확인: 아래를 치면 `3.12.11 3.13.3` 처럼 Python·GDAL 버전이 나오면 준비 끝입니다.
```
python -c "import sys; from osgeo import gdal; print(sys.version.split()[0], gdal.__version__)"
```

※ 터미널 창을 닫으면 이 설정이 사라집니다. 새 창을 열었으면 위 두 줄을 다시 붙여 넣으세요.

## 3. config.py 고치기

편집기로 엽니다 (둘 중 하나).
```
code config.py
```
VS Code 가 없으면 `open -a TextEdit config.py` 로 열고, 메뉴 **편집 → 대치 → "스마트 따옴표"를 끕니다** (켜져 있으면 `"` 가 `“` 로 바뀌어 코드가 깨집니다).

`Command + F` 로 줄을 찾아 **줄 전체를** 아래처럼 바꾸고 저장(`Command + S`)합니다.

| 찾을 줄 (처음 모습) | 바꿀 내용 |
|---|---|
| `DATA_ROOT_MAP = r"D:\data\수치지형도"` | `DATA_ROOT_MAP = r"testdata/map"` |
| `DATA_ROOT_DEM = r"D:\data\DEM5m"` | `DATA_ROOT_DEM = r"testdata/dem"` |
| `DATA_ROOT_PARCEL = None` | `DATA_ROOT_PARCEL = r"testdata/parcel"` (06 연습용) |
| `AREA_BBOX = None` | `AREA_BBOX = [200000, 545000, 201000, 546000]` (연습 구역 1, 아래 설명) |
| `EDGE_BUFFER = 500` | `EDGE_BUFFER = 100` **(연습에서만! 안심구역에서는 500 그대로)** |

줄 끝의 `# ★ ...` 설명 글은 남겨 둬도 되고 지워도 됩니다.

**연습용 bbox 두 개** (가짜 데이터 범위 x 200,000~201,000, y 545,000~547,000 을 위아래 반으로 나눔):

| 연습 구역 | config.py 에 넣을 줄 |
|---|---|
| 1 (남쪽 절반) | `AREA_BBOX = [200000, 545000, 201000, 546000]` |
| 2 (북쪽 절반) | `AREA_BBOX = [200000, 546000, 201000, 547000]` |

**EDGE_BUFFER 를 연습에서만 100으로 바꾸는 이유**: 가짜 데이터는 1 × 2 km 로 작아서, 반으로 나누면 1 × 1 km 입니다.
잘린 선과 데이터 가장자리에서 500m 안쪽을 모두 빼면 남는 건물이 0채가 되고, 05 가 `min() iterable argument is empty` 로 멈춥니다 (실제로 해 봄).
진짜 구역은 대상 구 둘레를 1,000m 넓혀 잘랐기 때문에 이런 일이 없습니다. **안심구역에서는 EDGE_BUFFER 를 절대 줄이지 마세요.**

저장했으면 제대로 바뀌었는지 확인합니다.
```
grep -n "^DATA_ROOT_MAP\|^DATA_ROOT_DEM\|^DATA_ROOT_PARCEL\|^AREA_BBOX\|^EDGE_BUFFER" config.py
```
→ 다섯 줄이 위 표의 "바꿀 내용" 대로 보여야 합니다.

## 4. 연습 구역 1 돌리기: 01 → 02 → 03 → 06 → 04 → 05

한 줄 치고, 끝나면 화면의 숫자를 확인하고, 다음 줄을 칩니다. 연습 결과를 오른쪽 칸에 적어 두었습니다.

| 단계 | 명령 | 화면에서 볼 줄 | 기준 | 연습 결과 (구역 1) |
|---|---|---|---|---|
| 01 | `python 01_inspect.py` | 2번째 줄 `Python … / GDAL … / scipy …` | 버전이 나오면 됨 (안심구역: Python 3.9.5 / GDAL 3.7.2) | Python 3.12.11 / GDAL 3.13.3 / scipy 있음 |
|  |  | `JIMOK(지목) 예시: {...}` | `대`·`도` 같은 한글. `???` 면 PARCEL_ENCODING = "CP949" | {'대': 1372, '도': 228} |
|  |  | `필드 [...] ← PNU, EMD_CD, JIMOK 이 있어야 함` | 세 이름이 모두 있음 | ['PNU', 'EMD_CD', 'JIMOK'] |
| 02 | `python 02_network.py` | `최대 연결망 노드 비율 N%` | **90% 이상** | 100.0% (노드 1,294, 링크 1,353) |
| 03 | `python 03_hbi.py` | `건물 N개 중 주거 M개 (네트워크 연결 N%)` | **95% 이상** | 116개 중 주거 91개, 100.0% |
|  |  | `데이터 경계 …m 이내 건물 N개 (x%)` | 구역별 실행에서는 높게 나와도 정상 | 100m 이내 29개 (31.9%) |
| 06 | `python 06_parcel.py` | `필지 N개` | 0 이 아님 | 필지 462개 |
|  |  | `그중 지목 '대' 필지 수` | **0 이 아님** (0 이면 01 의 JIMOK 확인으로) | 50 |
| 04 | `python 04_validate.py` | `선정지 재현:` 아래 5줄, `구간 재현:` | 멈추지 않고 끝나면 됨 (가짜 데이터라 선정지 값은 비어 있음) | 선정지 5줄 모두 0, 구간 1줄 |
| 05 | `python 05_export.py` | 마지막 줄 `완료 → output/ (반출 신청 대상)` | 이 줄이 나오면 성공 | 나옴. `→ output/dong_hbi.csv (행정동 2개)` |

※ 에러가 나면 빨간 글씨 대신 `Traceback (most recent call last):` 로 시작하는 여러 줄이 나옵니다. 마지막 줄을 적어 두세요.

## 6. 안심구역(Windows)에서 다른 점

| 항목 | 이 맥 (리허설) | 안심구역 (Windows, QGIS 3.32) |
|---|---|---|
| 명령창 | 터미널 + 1번의 `python()` 두 줄 | 시작 메뉴 → QGIS 3.32 → **OSGeo4W Shell**. 설정 없이 바로 `python` |
| 폴더 이동 | `cd ~/evenly_rehearsal/hbi` | `cd /d D:\작업폴더\hbi` (드라이브가 다르면 **`/d`** 가 있어야 이동됨) |
| 번들 풀기 | `python hbi_code_bundle_v4.txt` | 같음 |
| 가짜 데이터 | `python tools/make_test_data.py` | **하지 않음** (진짜 데이터 사용) |
| 편집기 | `code config.py` 또는 TextEdit (스마트 따옴표 끄기) | 파일 탐색기에서 config.py 오른쪽 클릭 → 연결 프로그램 → **메모장**. 저장할 때 인코딩 UTF-8 유지 |
| 데이터 경로 | `r"testdata/map"` (슬래시) | `r"D:\data\수치지형도"` 처럼 **역슬래시 + 앞에 `r`**. `r` 을 빼면 `\d`, `\n` 이 특수문자로 읽혀 경로가 깨짐. 따옴표 안 경로는 센터가 알려준 실제 폴더로 |
| AREA_BBOX | 연습 구역 1·2 (위 표) | `1차방문_구역별실행.md` 의 A·B·C·D 네 줄 (A → B → C → D 로 네 번) |
| EDGE_BUFFER | 연습에서만 100 | **500 그대로. 줄이지 않음** |
| 06 필지 경로 | `r"testdata/parcel"` | `DATA_ROOT_PARCEL = r"센터가 알려준 필지 폴더"` (서울 파일만 있는 폴더). 필지를 못 받았으면 `None` 그대로, 06 건너뜀 |
| 폴더 이름 바꾸기 | `mv output output_A` | `ren output output_A` (또는 탐색기에서 이름 바꾸기). 복사가 아니라 이름 바꾸기 |
| 설정 확인 | `grep -n "^AREA_BBOX" config.py` | `findstr /b "AREA_BBOX" config.py` |
| QGIS Python 콘솔로 할 때 | (연습 안 함) | config 를 바꾼 뒤 `import importlib, config; importlib.reload(config)` |
| 끝나면 | 폴더 지워도 됨 | `AREA_BBOX = None` 으로 되돌려 두기. `output_A`~`output_D` 네 폴더를 반출 신청 |
