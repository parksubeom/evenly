# 밖에서 공개데이터로 예비 결과 만들기 (계획, 화요일 반입 이후)

목적: 안의 결과(5~7일 뒤)를 기다리는 동안, **같은 모델·같은 형식**의 결과를 공개데이터만으로 만들어 기획서 "예비판"을 빌드한다. 반입과는 무관하다.

## 입력

| 항목 | 공개데이터 | 지금 상태 | 비고 |
|---|---|---|---|
| 길 | 서울시 자치구별 도보 네트워크 공간정보 (112MB, `data_public/raw`) | 있음 | `tools/public_baseline.py` 가 이미 읽어 노드·링크로 만듦 (30m 분할, 1m 반올림, 5% 이상 연결망 남김) |
| 높이 | AWS Terrain Tiles terrarium z15 (약 30m급) | 캐시 있음 (`data_public/raw/terrain_cache`) | public_baseline 과 같음. 5m DEM 보다 거칠다는 점을 모든 장에 표시 |
| 출발점(집) | **GIS건물통합정보** 주거 건물 (주용도 단독·공동주택) 도형의 대표점 | 파일 없음 | 들어오면 `tools/prep_gis_building.py` 로 8개 구 gpkg 를 만들고 그대로 씀 |
| 출발점 대안 | 건축물대장 표제부(있음) + 공개 지번 좌표 | 검토만 | 대장에는 좌표가 없음. 지번 → 좌표는 주소정보누리집 위치정보요약DB(건물 중심점) 또는 연속지적도(필지 대표점)가 필요. 둘 다 별도 내려받기라 GIS건물통합정보가 없을 때만 검토 |
| 목적지 | 약국 (`건강_약국_서울특별시.csv`, 좌표 열 있음), 지하철 엘리베이터 (`서울시 지하철역 엘리베이터 위치정보.csv`, WKT) | 있음 | 의료시설·노유자시설은 GIS건물통합정보의 용도(의료·노유자)로 함께 뽑음 |
| 계단 | 없음 | — | 공개 도보 네트워크에 계단 구분이 없음 → 휠체어 결과는 "계단 미반영" 표시 |

## 만드는 것

1. `tools/public_prelim.py` (새로): public_baseline 의 네트워크·지형 부분을 함수로 떼어 내 재사용하고, `analysis/hbi/lib/model.py`·`lib/qgraph.py` 를 **그대로** 불러 03·05 와 같은 계산·집계를 함 (모델 무변경).
   - 출발점: 대상 5개 구 주거 건물, 경계 제외 규칙(EDGE_BUFFER)·격자(250m)·비식별(5개 미만 제외)도 같게
   - 결과 폴더 `results/public_prelim/`: `summary.csv`, `grid_hbi.csv`, `dong_hbi.csv`, `validation_sites.csv`, `run_meta.csv` (안의 반출과 같은 열)
   - 표지: `_source.txt` 에 `public` (가짜 결과의 `fake` 와 다름)
2. 기획서 파이프라인 (`tools/evenly_common.py`, `prepare_deck_data.py`, `deck/`):
   - `is_public_dir()` 추가. `source` 가 `public` 이면 모든 장 머리에 **"공개데이터 예비 결과 (LX 미반영)"** 띠, 파일 이름 끝에 `_예비판`
   - 가드: `build:real` 은 `public` 표지가 있으면 멈춤(지금의 fake 가드와 같은 방식). `build:public` 은 `results/public_prelim` 만 받음. real 결과 폴더(`results/raw_export`)에 public 파일이 섞여 있으면 멈춤
   - 공개 대조군(18장)과 숫자가 겹치지 않게: 예비판에서는 18장을 "예비판이라 비교 없음" 으로
3. 시험: 가짜 결과로 예비판 빌드 1회, real 빌드가 public 폴더를 거부하는지, public 빌드가 real 폴더를 거부하는지

## 걸리는 시간 (예상)

| 일 | 예상 |
|---|---|
| public_prelim.py (public_baseline 재사용, 출발점·목적지·집계) | 반나절~1일 |
| GIS건물통합정보 받기·8개 구로 자르기 (`prep_gis_building.py` 이미 있음) | 1~2시간 (파일이 오면) |
| 계산 (8개 구 공개 네트워크, 목적지 4종) | 수 분~30분 (구역 A 크기 공개 네트워크로 02 가 4~16초였던 것에서 어림) |
| 파이프라인 표지·가드·띠 + 시험 | 반나절 |
| 합계 | 약 1.5일 (GIS건물통합정보가 있을 때). 없으면 출발점 대안 검토에 반나절 더 |

## 하지 말 것

- 모델·HBI 계산 바꾸기 (lib 를 그대로 불러 씀)
- 예비판 숫자를 real 결과처럼 쓰기 (모든 장에 표시, 가드로 섞임 방지)
- 공개데이터의 개별 건물 값 출력 (안과 같은 비식별 규칙)
