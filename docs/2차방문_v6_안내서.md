# 2차 방문 v6 따라하기 (안심구역 · 10/13~)

**컬러로 인쇄하세요** (검은 입력 상자·빨간 번호·초록/빨강 칸을 색으로 구분합니다).

**어느 안내서를 쓰나**: 작업 폴더에 **`hbi_code_bundle_v6.txt`** 가 있으면 이 안내서. v6 는 자료가 어떻게 생겼든 **코드를 고치지 않고** 맞춥니다. 폴더 주소를 하나씩 적던 v5 와 달리, **자료 맨 위 폴더 하나만** 알려 주면 `setup` 이 나머지를 찾습니다.

**읽는 법 — 무엇을 입력하나**
- **"입력" 이 붙은 검은 상자 안의 글자만** 명령창에 그대로 칩니다. 위의 "하는 일" 은 설명이라 치지 않습니다.
- 문장이나 표 속의 `$ python check.py` 처럼 **검은 칸**도 입력할 명령입니다. **회색 칸**은 화면이나 파일에서 찾아볼 글자라 치지 않습니다.
- `E:\제공자료` 자리에는 단계 0 ① 주소, `D:\작업폴더` 자리에는 ② 주소를 칩니다. 그림 속 빨간 번호 ①②③ 은 그 장의 글에서 "그림 ①" 처럼 가리키는 곳입니다.

| 순서 | 할 일 | 입력 |
|---|---|---|
| 단계 0~2 | 준비 → 명령창 → 번들 풀기 | `$ python hbi_code_bundle_v6.txt` |
| 단계 3 | 준비 도우미: 자료를 찾아 설정을 채움 (질문에는 **Enter**) | `$ python setup.py E:\제공자료` |
| 단계 4 | 출발 전 점검 (멈추면 mapping.txt 몇 줄 고치기) | `$ python check.py` |
| 단계 5 | 분석 (멈추면 그 번호부터 다시: 단계 6) | `$ python run_all.py` |
| 단계 7 | 실측 좌표 넣고 시설 효과·추가 분석 | `$ python run_all.py --from 09` 등 |
| 단계 8 | 반출: `output` 폴더 하나 (`work` 는 반출 안 함) | |

**꼭 지킬 것**: 받은 자료 폴더는 **옮기거나 지우지 않습니다** (쓸 폴더는 setup 이 골라 적어 둠) · `EDGE_BUFFER` 는 바꾸지 않습니다 · 반출은 `output` 만

## 단계 4-2. check 가 멈췄을 때: mapping.txt 고치기

할 일: `!! 멈춤:` 줄과 그 아래 `→` 줄을 읽고, 대부분은 **mapping.txt 한 줄**을 고칩니다.

1. 그림 ① 이 멈춘 이유, ② 가 할 일입니다.
2. `$ notepad mapping.txt` 로 열어 Ctrl+F 로 키를 찾고, **`=` 오른쪽만** 고쳐 저장합니다 (그림 ③, `#` 뒤 설명은 그대로).
3. `$ python check.py` 를 다시. 폴더 선택을 다시 하려면 `$ python setup.py E:\제공자료` 를 다시 쳐도 됩니다 (고친 대상 구 등은 남음).

```screen cmd 멈춤 예: 강서구 폴더가 빠졌을 때
  ⟦1⟧!! 멈춤: 대상 구가 자료 범위 밖: 강서구⟦/⟧
     ⟦2⟧→ 그 구의 수치지형도 폴더가 map_folders 에 있는지 (python setup.py 다시), AREA_BBOX 가 그 구를 덮는지 확인⟦/⟧
```

```screen notepad mapping.txt (고칠 때는 = 오른쪽만)
⟦3⟧building_attr_mode = register⟦/⟧  # 건물 용도·층수를 어디서: layer(건물 칸) / register(건축물대장) / all(모든 건물을 집) / stop

```

| 멈춤 줄 | 고칠 곳 |
|---|---|
| `대상 구가 자료 범위 밖: ○○구` | 그 구 폴더가 setup 표에서 × 였으면 setup 다시 → 번호로 ○. 자료에 아예 없으면 담당자에게 요청 |
| `건물 레이어에 용도 칸이 없음` | `building_attr_mode = register` (건축물대장이 없으면 `all`) |
