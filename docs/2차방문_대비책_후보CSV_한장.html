대비책 — v6.3 이 들어오지 않았을 때 (v6.2 + 후보 CSV)

쓰는 때: 작업 폴더에 hbi_code_bundle_v6.3.txt 가 없고, interventions_candidates.csv 가 들어왔을 때만. v6.3 이 있으면 이 종이는 쓰지 않습니다 (v6.3 안내서·카드).
이 CSV = 공개 자료 리허설에서 v6.3 후보 자동이 찾은 경사 구간 다섯 곳의 양 끝 좌표 + v6.2 에 원래 있던 봉천 줄. 안심구역 자료에서 나온 좌표가 아님. 결과 파일에는 좌표가 나가지 않음

순서 (안내서·카드는 인쇄 폴더 _대비책_v6.2 의 v6.2 판)

  1. v6.2 그대로: 안내서 v6.2 단계 0~5-3 (python hbi_code_bundle_v6.2.txt → cd hbi6 → python setup.py → python check.py → python run_all.py --modes auto,all). 관악 실측을 했으면 단계 7 (--from 04) 까지 먼저 끝냄. 천천히 잰 분은 기록지에만 (v6.2 의 od_pairs 에는 칸이 없음)
    단 하나 다른 것: setup 의 7. 상호제공 CSV 끝 질문 위 파일 경로를 config.py 에 넣을까요? (y/n, Enter = y) 에만 n Enter. v6.2 는 SKT 유동인구를 행정동 합계 그대로 내므로 (v6.3 은 구 평균 = 1.0 지수) 상호제공 자료를 쓰지 않음. KCB·교통사고도 함께 빠짐 (기획서 21·22장은 공개 자료판으로 나옴)
  2. 후보 CSV 로 바꾸기 (hbi6 폴더에서, 한 줄):
    copy /Y ..\interventions_candidates.csv external\interventions.csv
    Windows 가 1개 파일이 복사되었습니다. 를 띄우면 됨. 지정된 파일을 찾을 수 없습니다. → CSV 가 박수범 폴더에 없음 (담당자에게 확인)
  3. 09 부터 고른 방식만 다시:
    python run_all.py --from 09 --modes auto
    all 방식에는 후보를 넣지 않음 (방식끼리 수를 빼서 몇 채가 드러나지 않게). 그래서 맨 위에 아래 줄이 나오는 것이 정상: all 결과는 지우지 않고 work 로 옮겨지며 반출에서 빠짐 (기획서는 고른 방식만 씀)
    # 이번 실행에 없는 지난 결과 1개를 반출 폴더에서 뺌 → work/old_output/… (지우지 않음, 반출하지 않음): output/all/
  4. 화면 확인: 09 에 시설 줄이 여섯 (봉천 + 후보1 (리허설) ~ 후보5 (리허설)), 끝에 # 끝: 정상 (종료 코드 0). 리허설 화면:
    [13:01:18] 시설 후보1 (리허설) [elevator, planned] 길이 54m, 통과 1.9분 (대기 60초, 1m/s), 높이 차 11.1m (DEM 5m, 참고) … [13:01:33] 완료 → output/intervention_summary.csv (21행), intervention_grid.csv (27행), intervention_dong.csv (15행)
    숫자는 실제 자료라 다름. 후보 끝점이 실제 길에서 멀다는 !! … 좌표 확인 이나 건너뜀 이 붙으면 그 후보 이름만 메모 (멈추지 않음. 건너뛴 후보는 결과 없음). 멈추면 메모 카드 다섯 줄 (v6.2 안내서 단계 6·9)
  5. 반출 신청 (v6.2 안내서 단계 8): hbi6\output 하나. 신청 설명에 두 줄:
    • 시설 단위 수혜 건물 수는 개수만 포함하며 건물 속성·좌표는 없음 (1~4채는 "5채 미만"으로 적음)
    • 후보 시설 5곳은 공개 자료로 미리 정한 위치이며, 결과에는 시설 이름별 집계만 있고 좌표·건물 단위 정보는 없음
