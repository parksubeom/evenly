# 1차 방문 v5 따라하기 (안심구역 · 10/2 금)

**컬러로 인쇄하세요** (검은 입력 상자·빨간 번호·초록/빨강 칸을 색으로 구분합니다).

**어느 안내서를 쓰나**: 안심구역 PC 의 작업 폴더에 **`hbi_code_bundle_v5.txt`** 가 있으면 이 안내서, 없고 `hbi_code_bundle_v4.txt` 만 있으면 **`1차방문_안내서.pdf` (v4)** 를 씁니다.
v5 는 구역을 나누지 않고 **한 번에** 돌립니다 (서로 떨어진 구도 한꺼번에 계산하도록 고친 판).

**읽는 법 — 무엇을 입력하나**
- **"입력" 이 붙은 검은 상자 안의 글자만** 명령창에 그대로 칩니다. 위의 "하는 일" 은 설명이라 치지 않습니다.
- 문장이나 표 속의 `$ notepad config.py` 처럼 **검은 칸**도 입력할 명령입니다. **회색 칸**은 화면이나 파일에서 찾아볼 글자라 치지 않습니다.
- `D:\작업폴더` 자리에는 단계 0 ④ 에 적은 주소를 칩니다. 그림 속 빨간 번호 ①②③ 은 그 장의 글에서 "그림 ①" 처럼 가리키는 곳입니다.

| 순서 | 할 일 | 입력 |
|---|---|---|
| 단계 0~4 | 준비 → 명령창 → 번들 풀기 → 설정 파일 주소 → 자료 점검 (v4 와 거의 같음) | `$ notepad config.py`, `$ python 01_inspect.py` |

| 단계 8 | 반출: `output` 폴더 하나 (`work` 는 반출 안 함) | |

센터에서 확인한 것: 이용 09:00~18:00 · 메모리 64GB · OSGeo4W Shell 있음 · 국토정보필지는 시도별 shp, UTF-8 · 상호제공데이터(SKT·KCB·교통사고)는 센터가 준비 · 반출 심사 3~4일 · 손메모 반입 가능

## 단계 1. 명령창 열기

할 일: 명령창(글자로 컴퓨터에 지시하는 검은 창)을 엽니다.

1. 화면 왼쪽 아래 **시작 단추**를 클릭합니다.
2. 키보드로 `$ OSGeo4W` 를 칩니다 (검색 칸에 입력).
3. 목록에 나온 **OSGeo4W Shell** 을 클릭합니다(그림 ①). 검은 창이 뜹니다.
4. 입력 상자 속 명령은 검은 창에 **그대로 타자로 치고 Enter**. 명령이 끝나면 맨 아래에 `D:\작업폴더>` 처럼 **폴더 주소와 `>`** 가 다시 나타납니다. 그 전에는 다음 명령을 치지 않습니다.

```screen start
OSGeo4W
⟦1⟧OSGeo4W Shell⟦/⟧
```

**명령을 치기 전에 한/영 키로 영어 입력 상태인지 확인합니다.** 한글 상태면 `python` 이 `ㅔㅛ쇄ㅜ` 처럼 입력됩니다. 그렇게 쳤으면 Backspace 로 지우고 한/영 키를 한 번 누른 뒤 다시 칩니다.

**실행 중에는 검은 창 안을 클릭하지 않습니다.** 클릭하면 "선택" 상태가 되어 멈춥니다. 창 맨 위 제목 앞에 `선택` 이 보이면 **Esc**. 마우스 휠로 올려 보는 것은 괜찮습니다.

## 단계 5-2. 분석 끝난 뒤

할 일: 숫자를 메모 칸에 적고, 결과가 다 나왔는지 봅니다.

1. 맨 아래에 `D:\작업폴더\hbi>` 가 다시 보이면 끝(그림 ④). 그 위에 그림 ③ `완료 → output/ (반출 신청 대상)` 이 있는지 봅니다.
2. 마우스 휠로 **위로 올려** 그림 ① 줄의 **남긴 연결망 개수**와 **노드 비율 %** 를 메모 칸에 적습니다.
