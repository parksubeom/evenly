# 리허설 코드 대응표 (공개 값 → 정의서 코드, **리허설용으로만**)

10/8 결정: 공개데이터로 만든 "관악구 대역 리허설"에서만 쓴다. 안심구역 분석 코드(`analysis/hbi`)에는 이 대응을 넣지 않는다. 안심구역 자료는 처음부터 정의서 코드이거나(메모로 확인 예정) `lib/codebook.py` 가 코드명을 코드로 바꾼다.

- 만드는 도구: `tools/make_public_rehearsal.py` (이 표와 같은 대응이 코드 맨 위에 있음)
- 결과 표지: `results/public_rehearsal/<이름>/_source.txt` = `public_rehearsal`
- 기획서: `npm run build:rehearsal` 만 받음 (모든 장에 "공개 대역 리허설 — 제출 금지" 띠, 파일 `deliverables/_rehearsal_기획서.pptx`). `build:real` 은 이 표지를 보면 멈춤

원칙: 이름이 같은 것만 잇는다. 대응이 없는 값은 **비워 둔다** (정의서에 없는 코드를 지어 넣지 않음).

## 4. 건물 종류 (BULD_SE)

GIS 에는 종류 칸이 없다. 용도명이 **단독주택**인 것만 BDC001 일반주택으로 적고 나머지는 비운다. 공동주택은 연립(BDC002)·아파트(BDC003)를 가를 수 없어 비운다. 분석 코드는 용도가 빈 건물에만 종류를 보므로, 결과에는 거의 영향이 없다.

## 값 형식

기본은 코드(`BDU001`). `--style name` 이면 정의서 코드명(`주거용단독주택`)으로 쓴다. 1차 자료의 실제 형식은 메모로 확인 전.
