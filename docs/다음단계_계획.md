# 대회 이후 발전 계획

본선(11/18~19)은 이미 있는 결과로 발표·질의응답만 하는 자리입니다. 아래는 대회가 끝난 뒤 할 일이며, 기획서 숫자는 바꾸지 않습니다.
기획서 25장 "한계와 대응"의 다음 단계 줄과 같은 내용입니다.

## 1. 분석 범위 (25장 다음 단계)
- **건축물대장 연결 개선 → 주거 기준으로**: 10/19 연결률이 대장 45%·건물 칸 25%라 모든 건물을 출발점으로 계산함. 연결을 고쳐 주거 건물만 출발점으로
- **사고·유동인구 원자료 결합**: 이번에는 공개 자료(보행노인 사고다발지·서울 생활인구)만 씀. 사고 원자료·유동인구 원자료를 붙여 동 안의 짧은 외출과 사고를 같이 보기
- **현행 보행속도 0.7m/s 적용**: 이번 결과는 경찰청 매뉴얼 개정 전 0.8m/s. 왕복 추가 시간은 ×8/7 이 되고 HBI 는 같음 (29장, 해석적 계산)

## 2. 코드 고칠 것 (10/19·10/20 방문에서 확인, 지금은 기록만)
1. int32 넘침: `key[a * n + b]` 같은 정수 배열 곱 패턴을 코드 전체에서 찾아 `int()` 로 (윈도 numpy 기본 정수가 int32). 10/19 현장에서 lib/model.py 150줄만 고쳐 통과
2. 06 필지 고유칸 pnu 인식 실패, 필지 지목 인코딩("칸 없음·한글 0%"), register 연결률 45% 원인
3. config 수정이 안 들어간 원인 (19일 한 장 문구·확인 명령 — 확인 줄을 쳤는지, 저장이 됐는지). 107줄 ELDER_SPEED 가 반영되지 않아 0.8m/s 로 계산됨

## 3. 자료 이용 조건
- 유료 서비스로 갈 경우 서울시 사진(15장, 서울균형발전포털 「서울 오르락」 공공누리 제4유형 = 비상업적 이용만)은 직접 촬영본으로 교체
