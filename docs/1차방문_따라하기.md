# 1차 방문 따라하기 (안심구역, Windows)
자세한 이유와 설명은 상세판 `1차방문_구역별실행.pdf` 에 있습니다. 이 종이는 순서대로 따라 하기만 하면 됩니다.

## 한 줄 요약
**① 준비(한 번) → ② 구역별 실행(A·B·C·D 네 번) → ③ 반출**
분석 코드(v4)는 서로 이어진 길 묶음 가운데 가장 큰 하나만 계산하므로, 떨어져 있는 네 동네 묶음을 한 번에 돌리면 세 묶음이 빠집니다. 그래서 분석 범위를 바꿔 가며 네 번 돌립니다.

## ① 준비 (한 번만)

□ **1. 담당자에게 물을 것 (폴더 4개)**

| 무엇 | 적어 둘 폴더 |
|---|---|
| 수치지형도(.shp 지도 파일) 폴더 | |
| 높이 자료 DEM 5m(.img) 폴더 | |
| 국토정보필지 폴더 (서울 파일만, 못 받으면 비움) | |
| 작업 폴더 (번들 파일을 두고 결과가 생길 곳) | |

□ **2. 명령창 열기**: 시작 메뉴 → QGIS 3.32 → **OSGeo4W Shell** (검은 창). 아래 명령은 모두 이 창에 한 줄씩 붙여 넣고 Enter.

□ **3. 번들 풀기** (작업 폴더로 이동 → 풀기 → 생긴 hbi 폴더로 들어가기. `D:\작업폴더` 는 1번에서 받은 작업 폴더로)
```
cd /d D:\작업폴더
```
```
python hbi_code_bundle_v4.txt
```
```
cd hbi
```

□ **4. 설정 파일 열기**
```
notepad config.py
```
Ctrl+F 로 아래 4줄을 찾아, 따옴표 안만 1번의 폴더로 바꾸고 저장(Ctrl+S). **따옴표 앞의 `r` 은 지우지 않습니다** (지우면 경로가 깨짐).
```
DATA_ROOT_MAP = r"수치지형도 폴더"
DATA_ROOT_DEM = r"DEM 5m 폴더"
DATA_ROOT_PARCEL = r"국토정보필지 폴더"
AREA_BBOX = [194500, 548300, 203400, 560200]
```
- 필지를 못 받았으면 `DATA_ROOT_PARCEL = None` 그대로 둡니다.
- 마지막 줄 `AREA_BBOX` 는 분석 범위(첫 구역 A). 처음 모습은 `AREA_BBOX = None` 입니다.

□ **5. 자료 점검**
```
python 01_inspect.py
```

| 화면 문구 | 뜻 → 할 일 |
|---|---|
| `shp 파일 총 0개` | 지도 폴더를 못 찾음 → `DATA_ROOT_MAP` 따옴표 안 확인 |
| `DEM 5m: 파일 0개` | 높이 자료를 못 찾음 → `DATA_ROOT_DEM` 확인 |
| `[없음] road_cl` 또는 `sidewalk_cl`, `building` | 꼭 필요한 지도 파일이 없음 → 담당자에게 파일 이름 확인 (`tunnel`·`overpass` 의 [없음]은 괜찮음) |
| `JIMOK(지목) 예시: {'대': …}` | 한글이 보이면 정상. `???` 처럼 깨지면 config 의 `PARCEL_ENCODING = "CP949"` 로 바꾸고 다시 5번 |
| `필드 [...]` 에 `PNU, EMD_CD, JIMOK` 이 없음 | 필지 파일이 다름 → 필지는 건너뜀 (`DATA_ROOT_PARCEL = None`), 메모 |

## ② 구역별 실행 (A□ B□ C□ D□ 네 번)

| 구역 | 동네 | config.py 에 넣을 줄 |
|---|---|---|
| A□ | 종로구·중구 | `AREA_BBOX = [194500, 548300, 203400, 560200]` |
| B□ | 관악구 | `AREA_BBOX = [190100, 536300, 200000, 545000]` |
| C□ | 광진구 | `AREA_BBOX = [203900, 546100, 211100, 553700]` |
| D□ | 강서구 | `AREA_BBOX = [178200, 546400, 190500, 557200]` |

□ **1. 분석 범위 바꾸기**: `notepad config.py` → `AREA_BBOX` 줄을 위 표의 그 구역 줄로 통째로 바꾸고 저장 (A 는 ①-4 에서 이미 넣음)

□ **2. 분석 명령 5줄** (위에서부터 차례로. 하나가 끝나 커서가 다시 깜빡이면 다음 줄)
```
python 02_network.py
```
```
python 03_hbi.py
```
```
python 06_parcel.py
```
```
python 04_validate.py
```
```
python 05_export.py
```
- `06_parcel.py` 는 필지를 받았을 때만. 못 받았으면 건너뜀
- 05 의 마지막 줄이 `완료 → output/ (반출 신청 대상)` 이면 성공

□ **3. 결과 폴더 이름 바꾸기** (구역 글자만 바꿔서: output_A, output_B, output_C, output_D)
```
ren output output_A
```

□ **4. 다음 구역으로**: 표의 다음 구역 칸에 체크하고 1번부터 다시

**볼 숫자 2개** (구역마다 메모)

| 명령 | 화면 문구 | 괜찮은 값 |
|---|---|---|
| 02 | `최대 연결망 노드 비율 N%` (길 네트워크가 한 덩어리로 이어진 비율) | **90% 이상**. 낮으면 메모만 하고 계속 |
| 03 | `데이터 경계 500m 이내 건물 N개 → 통계에서 제외 예정 (x%)` (자료 가장자리 가까워 빼는 집 비율) | **100% 가 아님**. 높게 나와도 100% 만 아니면 계속 |

## 막혔을 때

| 화면에 나온 것 | 뜻 | 할 일 |
|---|---|---|
| `'python'은(는) 내부 또는 외부 명령…이 아닙니다` | 일반 명령창에 쳤음 | OSGeo4W Shell 을 다시 열고 `cd /d D:\작업폴더\hbi` |
| `can't open file … No such file or directory` | hbi 폴더 밖에 있음 | `cd /d D:\작업폴더\hbi` 로 이동 후 다시 |
| 06 에서 `지목 '대' 필지가 0개입니다` | 필지 한글이 깨짐 | config 의 `PARCEL_ENCODING = "CP949"` 로 바꾸고 06 다시 |
| 05 에서 `min() iterable argument is empty` | 분석 범위 안에 계산할 집이 0채 | 03 의 경계 비율이 100% 인지, `AREA_BBOX` 줄이 표와 같은지 확인. 안 풀리면 `ren output output_A_실패` 하고 다음 구역 |

**EDGE_BUFFER 는 바꾸지 않습니다** (자료 가장자리 500m 를 빼는 설정. 맥 리허설에서만 100 으로 씀).

## ③ 마무리

□ 네 구역이 끝나면 `notepad config.py` → `AREA_BBOX = None` 으로 되돌려 저장

□ **반출할 폴더**: `output_A`, `output_B`, `output_C`, `output_D` (hbi 폴더 안)

□ **반출하지 않을 폴더**: `work` (집 한 채 단위 결과라 반출 금지), `output_?_실패`

□ **메모할 것 3가지**
1. 구역마다 02 의 길 네트워크 비율, 03 의 경계 비율
2. 멈춘 명령이 있으면 그 명령과 화면 마지막 줄 (그대로 옮겨 적기)
3. 01 점검에서 [없음]·깨진 글자처럼 예상과 다른 줄
