# 1차 방문 그림 안내 (안심구역 컴퓨터에서 할 일)

명령창이 익숙하면 따로 있는 **짧은 따라하기판(`1차방문_따라하기.pdf`, 종이 2장)** 만 봐도 됩니다. 이 안내서는 처음 해 보는 사람을 위한 것입니다.
한 장에 한 단계씩이고, 장마다 맨 위에 "0쪽"~"8쪽" 이름이 있습니다(5쪽은 두 장: 5쪽, 5쪽-2). 쪽마다 "할 일 → 따라 하기 → 화면 예시 → 성공하면/이상하면" 순서로 읽습니다.
그림 속 빨간 번호 ①②③ 은 그 쪽의 글에서 "그림 ①" 처럼 가리키는 곳입니다. 상자 속 명령은 **글자·띄어쓰기·기호까지 똑같이** 칩니다.

## 0쪽. 준비물과 물어볼 것

할 일: 가져갈 것을 챙기고, 담당자에게 폴더 네 곳의 주소를 받아 적습니다.

1. 챙길 것: 신분증, 이 안내서, 펜
2. 안심구역 담당자에게 아래 네 가지를 묻고, 오른쪽 칸에 **주소(폴더 위치)를 그대로** 적습니다.

| 물어볼 것 | 받아 적을 주소 |
|---|---|
| ① 수치지형도 폴더 (지도 파일이 있는 곳) | |
| ② DEM 5m 폴더 (높이 자료가 있는 곳) | |
| ③ 국토정보필지 폴더 (서울 필지. 못 받으면 "없음") | |
| ④ 작업 폴더 (우리 파일 `hbi_code_bundle_v4.txt` 를 둘 곳) | |

| 성공하면 | 이상하면 |
|---|---|
| 네 칸이 모두 채워짐 (③은 "없음"이어도 됨) | 주소를 모르겠다고 하면: "파일 탐색기에서 그 폴더를 열어 주세요"라고 부탁하고, 3쪽의 방법으로 주소를 복사 |

## 1쪽. 명령창 열기

할 일: 명령창(글자로 컴퓨터에 지시하는 검은 창)을 엽니다.

1. 화면 왼쪽 아래 **시작 단추**를 클릭합니다.
2. 키보드로 `OSGeo4W` 를 칩니다.
3. 목록에 나온 **OSGeo4W Shell** 을 클릭합니다(그림 ①). 검은 창이 뜹니다.
4. 이 안내서의 굵은 테두리 상자 속 명령은 검은 창에 **그대로 타자로 치고 Enter** 를 누릅니다. 다른 곳에서 글자를 복사해 왔다면, 검은 창 안에서 **마우스 오른쪽 클릭** 또는 **Ctrl+V** 로 붙여 넣을 수 있습니다.

```screen start
OSGeo4W
⟦1⟧OSGeo4W Shell⟦/⟧
```

명령이 끝나면 맨 아래에 `D:\작업폴더>` 처럼 **폴더 주소와 `>`** 가 다시 나타납니다(아래 그림 ②). 이것이 "다음 명령을 쳐도 된다"는 신호입니다.

```screen cmd 예: 2쪽에서 파일을 푼 뒤의 모습
D:\작업폴더>python hbi_code_bundle_v4.txt
완료: 파일 43개 → D:\작업폴더
다음: cd hbi  →  python 01_inspect.py   (README.md 참고)

⟦2⟧D:\작업폴더>⟦/⟧
```

| 성공하면 | 이상하면 |
|---|---|
| 검은 창이 뜨고, 맨 위 제목에 "OSGeo4W Shell" 이라고 쓰여 있음 | 목록에 없으면 담당자에게 "QGIS 의 OSGeo4W Shell 이 어디 있나요?"라고 묻기. **실행 중에는 검은 창을 닫지 않습니다** |

## 3쪽. 설정 파일에 폴더 주소 넣기

할 일: 메모장으로 설정 파일(`config.py`)을 열어, 0쪽에 적은 폴더 주소 ①②③ 세 개를 넣습니다 (④는 2쪽에서 이미 씀).

1. 아래 상자를 치고 Enter. 메모장이 열립니다.
2. **Ctrl+F** 를 누르고 `DATA_ROOT_MAP` 을 쳐서 그 줄을 찾습니다.
3. 따옴표 `"` 안의 글자만 지우고 0쪽 ① 주소를 넣습니다(그림 ①). **따옴표 앞의 `r` 은 지우지 않습니다.** 같은 방법으로 `DATA_ROOT_DEM` 에 0쪽 ② 주소를 넣습니다. `DATA_ROOT_PARCEL` 은 처음에 `None` 이라 따옴표가 없습니다: `None` 을 지우고 그림처럼 `r"0쪽 ③ 주소"` 를 씁니다. ③이 "없음"이면 `None` 그대로 둡니다. `DATA_ROOT_DEM1M` 줄은 그대로 둡니다. 줄 끝 `#` 뒤의 설명 글은 신경 쓰지 않습니다.
4. **Ctrl+S** 로 저장합니다. 메모장은 닫아도 됩니다.

```
notepad config.py
```

```screen notepad 바꾸기 전
DATA_ROOT_MAP = r"D:\data\수치지형도"     # ★ 수치지형도 .shp 파일들이 있는 폴더
DATA_ROOT_DEM = r"D:\data\DEM5m"          # ★ DEM 5m .img 파일들이 있는 폴더
DATA_ROOT_DEM1M = None                     # ★ DEM 1m 폴더 (비교 분석용, 안 쓰면 None 그대로)
DATA_ROOT_PARCEL = None                    #   국토정보필지 폴더 (2회차에 승인되면 경로 입력)
```

```screen notepad 바꾼 후 (주소는 예시)
DATA_ROOT_MAP = r"⟦1⟧E:\제공자료\수치지형도⟦/⟧"     # ★ 수치지형도 .shp 파일들이 있는 폴더
DATA_ROOT_DEM = r"⟦1⟧E:\제공자료\DEM5m⟦/⟧"          # ★ DEM 5m .img 파일들이 있는 폴더
DATA_ROOT_DEM1M = None                     # ★ DEM 1m 폴더 (비교 분석용, 안 쓰면 None 그대로)
DATA_ROOT_PARCEL = r"⟦1⟧E:\제공자료\필지⟦/⟧"                    #   국토정보필지 폴더 (2회차에 승인되면 경로 입력)
```

주소를 직접 치기 어려우면: 파일 탐색기(폴더 창)에서 그 폴더를 열고, 위쪽 **주소창의 빈 곳을 클릭**하면 주소가 파랗게 선택됩니다. **Ctrl+C** 로 복사해서 메모장의 따옴표 안에 **Ctrl+V** 로 붙여 넣습니다(그림 ②).

```screen explorer E:\제공자료\수치지형도
⟦2⟧E:\제공자료\수치지형도⟦/⟧
```

| 성공하면 | 이상하면 |
|---|---|
| 세 줄의 따옴표 안이 받아 적은 주소로 바뀌고 저장됨 | `r` 이나 따옴표를 지웠으면 그림처럼 `r"…"` 모양으로 되돌림. 저장을 잊으면 다음 단계에서 `shp 파일 총 0개` 가 나옴 |

## 4쪽. 자료 점검

할 일: 폴더 주소가 맞는지, 필요한 지도 파일이 다 있는지 확인합니다.

1. 아래 상자를 치고 Enter. 글자가 쭉 나오고, 맨 아래에 `D:\작업폴더\hbi>` 가 다시 보이면 끝입니다.
2. 그림 ① `shp 파일 총 N개` 의 N 이 0 이 아닌지 봅니다.
3. 그림 ② 에서 `sidewalk_cl`, `road_cl`, `building` 앞이 `[있음]` 인지 봅니다.
4. 그림 ③ `JIMOK(지목) 예시` 에 `대`, `도` 같은 한글이 보이는지 봅니다 (필지를 받았을 때만 나옴). 그 밖의 글자는 몰라도 됩니다.

```
python 01_inspect.py
```

`[없음]` 이 보이면 아래 표로 판단합니다.

| 화면 문구 | 뜻 → 할 일 |
|---|---|
| `[없음] building`, 또는 `sidewalk_cl`·`road_cl` **둘 다** [없음] | **분석 불가**: 집 또는 길 지도가 없음 → 멈추고 담당자에게 파일 이름 확인 |
| `sidewalk_cl`·`road_cl` 중 **하나만** [없음], 또는 `[없음] stairs` · `bus_stop` · `station` | **결과 약화**: 길 일부·계단·정류장·역이 빠짐 → 메모하고 계속 |
| `[없음] bridge` · `tunnel` · `overpass` | **괜찮음**: 다리·터널·육교 → 그대로 계속 |

| 성공하면 | 이상하면 |
|---|---|
| ① 0 이 아님, ② 세 줄 모두 `[있음]` (하나라도 `[없음]` 이면 위 표대로), ③ 한글이 보임 (필지가 "없음"이면 ③ 은 안 나와도 됨) | ① `shp 파일 총 0개` → 3쪽 `DATA_ROOT_MAP` 주소 확인. ③ `???` 처럼 깨지면 `notepad config.py` → Ctrl+F 로 `PARCEL_ENCODING` 을 찾아 `"UTF-8"` 을 `"CP949"` 로 바꾸고 저장, 이 쪽을 다시 |
