# v6 설계 (2차 방문용: 안심구역 안에서 자료에 스스로 맞추는 코드)

원칙: 모델·HBI 계산(`lib/model.py`, `lib/qgraph.py`, 네트워크 구축 규칙, 03 의 계산식)은 v5 와 같다. 바뀌는 것은 **자료를 찾고 읽는 부분**과 **어느 건물을 집계하나**뿐이다. 사용자는 코드를 고치지 않고 `mapping.txt` 몇 줄로 자료 차이에 대응한다.

## 파일 구조 (analysis/hbi, ★ = 새 파일)

| 파일 | 역할 |
|---|---|
| ★ `setup.py` | 대화형 준비: 자료 최상위 폴더 하나 → 하위 폴더 훑기 → zip 풀기 제안 → 레이어·DEM·필지·CSV 판별 → 폴더 자동 선택·AREA_BBOX 결정 → 칸 매핑 → `mapping.txt` 저장, `config.py` 경로·범위 줄 채움(원본 `config.py.bak`) |
| ★ `check.py` | 출발 전 점검. 말이 안 되면 멈추고 고칠 mapping 키를 알려 줌 → `output/check_report.txt` |
| ★ `mapping.txt` | `키 = 값  # 설명`. 칸 이름·레이어 코드·폴더 선택·대상 구·건물 용도 방식. 없으면 v5 기본값 |
| ★ `lib/mapping.py` | mapping.txt 읽기 → config 의 `LAYERS`·`COL`·`FIELD`·`MAP_FOLDERS`·`TARGET_GU` 등을 덮어씀. 별칭 사전 |
| ★ `lib/battr.py` | 건물 용도·층수 결정 (layer / register / all / stop). 03·14 가 같은 함수를 씀 |
| ★ `lib/area.py` | 구 경계(external/dong_boundary.geojson), 대상 범위, 폴더 범위 겹침, 건물 → 구 판정 |
| ★ `lib/schema.py` | 자료 구조 저장 (`output/schema/`, ogrinfo -so 수준, 값 없음) |
| ★ `lib/conout.py` | 콘솔 코드페이지와 상관없이 한글 출력, 화면 + 파일 동시 기록 |
| `lib/qio.py` | `iter_layer` 칸 이름 대소문자 무시(돌려주는 키는 요청한 이름), `find_files` 가 `map_folders` 만 읽음 |
| `run_all.py` | `--from 03`, 화면 + `output/runlog/` 기록, 실패 패턴 진단(`output/diagnose.txt`), 시작 때 `output/schema/` |
| 01~14 | 하드코딩 칸 이름 → `C.FIELD[...]`·`C.COL[...]`. 03 은 `battr` 사용 + 대상 구 건물만 출발점 |

## mapping.txt 키

| 무리 | 키 (기본값) |
|---|---|
| 범위 | `target_gu` (종로구,중구,관악구,광진구,강서구), `neighbor_gu` (성북구,성동구,동대문구), `map_folders` (비면 전부), `area_reason` (setup 이 적음) |
| 건물 | `building_attr_mode` (layer), `bld_use` (BPRP_SE), `bld_kind` (BULD_SE), `bld_floor` (BFLR_CO), `bld_ufid` (UFID, 참고) |
| 그 밖 레이어 칸 | `stair_kind` (ARSFCKD_SE), `bus_kind` (PTRFCKD_SE) |
| 필지 | `parcel_id` (PNU), `parcel_bldrgst` (BLDRGST_PK), `parcel_ufid` (UFID, 참고), `parcel_emd_cd` (EMD_CD), `jimok` (JIMOK), `sgg_nm` (SGG_NM), `emd_nm` (EMD_NM) |
| 건축물대장 | `register_join` (auto), `register_file` (external/building_register.csv), `reg_pk` (bldrgst_pk), `reg_pnu` (pnu), `reg_use_cd`, `reg_use_nm`, `reg_floor` (grnd_flr), `reg_area` (tot_area), `reg_main` (main_atch) |
| 레이어 코드 | `layer_building` (N3A_B0010000, 건물) 등 9개, 쉼표로 여럿 |

못 찾은 키는 `= ?` 로 저장하고 영향(어느 단계가 약해지거나 멈추는지)을 주석에 적는다.

## 규칙

| 규칙 | 내용 |
|---|---|
| 칸 찾기 | 대소문자 무시. 별칭 사전 기본값 = LX·국토지리정보원 정의서 이름(대문자) + 영문 소문자·한글·약어. 값 모양 검사는 표본 수백 개, 값은 화면·파일에 남기지 않음 |
| 폴더 선택 | 수치지형도 shp 가 2개 이상 하위 폴더로 나뉘면 폴더마다 범위를 읽어 대상 구 + 옆 구 경계와 겹치는 폴더만 제안 → Enter(동의)·번호로 바꿈 → `map_folders`. 폴더를 옮기거나 지우지 않음 |
| AREA_BBOX | 선택한 자료 범위가 (대상 구 + 옆 구 + 1km) 를 크게 넘으면(한 변 2km 이상) 그 범위로, 아니면 None. 값과 이유를 화면·mapping 에 적음 |
| 대상 구 집계 | 출발점(집)은 대상 구 안 건물만. 옆 구는 길·목적지로만. 대상 구를 비우면 v5 와 같음(전체) |
| 건물 용도 | layer: 건물 레이어 칸 / register: 건물 → 중심점이 든 필지 → 건축물대장. 한 필지에 여러 행이면 주건축물 → 연면적 최대 행의 용도, 층수는 최대 / all: 모든 건물이 집, 의료·노유자 건물 목적지 없음(약국 등만) → summary·run_meta 에 "용도 미구분" / stop: 중단 |
| 필지 ↔ 대장 연결 (10/3 결정) | `register_join = auto`(기본) / `pnu` / `pk`. 실제 자료에서 세 연결률을 모두 잼: (a) 필지번호 pnu, (b) 필지 `bldrgst_pk` ↔ 대장 번호, (c) 참고: 건물 UFID 가 필지 ufid 에 있는 비율. auto 는 (a)·(b) 중 높은 쪽, 같으면 **pnu**. 두 번호 체계는 섞지 않음. 근거: LX 정의서상 필지 BLDRGST_PK 는 **총괄표제부** 번호인데 받은 대장은 **표제부**라 같은 번호 체계라는 보장이 없음. 세 값은 check 화면·check_report·03 로그·run_meta 에 남음 |
| 건축물대장 반입 (10/3 결정) | 8개 구 CSV(14.3MB)를 번들과 **따로** 첨부. CSV 가 막히면 `.txt` 로 이름만 바꿈. 찾는 곳: `external/building_register.csv` → 같은 이름 `.txt` → 작업 폴더(hbi 바깥)의 `.csv`·`.txt` |
| 필지 | `owner_*`, `jiga_*` 칸은 읽지 않음 (필요한 칸 이름만 요청) |
| 메타데이터 | `output/run_meta.csv` (대상 구, 용도 방식, 연결률, AREA_BBOX·이유, 폴더 수). summary.csv 는 v5 형식 그대로이고, 뜻이 바뀌는 경우(대상 구로 건물을 뺐을 때, all 방식)에만 맨 끝에 `meta` 행을 붙임 → 표준 자료 회귀에서 md5 동일 |
| 멈춤 기준 (check) | 주거 0%·100%(all 제외), 건물→길 연결 50% 미만, 목적지 0개, 대상 구가 자료 범위 밖, 필수 레이어 없음 |

## 회귀 기준

표준 스키마 가짜 자료(`tools/make_test_data.py`)에서 v5(8c0c494)와 v6 의 `output/*.csv` md5 동일 (gpkg 는 저장 시각만 다름). 가짜 자료가 서초·강남 위치라, `target_gu` 를 비운 경우와 서초구,강남구로 둔 경우 두 번 비교한다.

## 10/6 추가: 2차 방문 성공률 올리기

| 기능 | 내용 |
|---|---|
| 결과 점검표 | run_all 끝에 `lib/rcheck.py` 가 주거 비율·용도 연결률·노드 비율·길 연결·경계 제외·HBI 중앙값·고위험 비율·목적지·선정지 백분위를 기대 범위와 비교 → [초록]/[노랑]/[빨강], 빨강이면 원인·고칠 mapping 키·`--from` 단계. `output/result_check.txt`. 기대 범위와 근거는 `docs/결과점검_기준.md` |
| 여러 방식 한 번에 | `python run_all.py --modes auto,all` (또는 register,all 등). 01·02 는 한 번, 03 부터 방식마다 `output/<방식>/`·`work/<방식>/` (길 네트워크 `work/network.npz` 공유). summary 에 `meta, 건물 용도 방식` 행. 기획서: `tools/prepare_deck_data.py --mode <방식>` (없으면 layer → register → gisbld → all 순서로 있는 것) |
| gisbld | GIS건물통합정보(`tools/prep_gis_building.py` → `external/gis_building.gpkg`)와 LX 건물의 겹침 면적이 가장 큰 GIS 건물의 용도·층수. 겹침이 LX 건물 면적의 30% 미만이면 연결 안 함. 연결률·평균 겹침률 출력 |
| auto | `building_attr_mode = auto` (setup 기본): check 가 표본 창에서 layer → register → gisbld → all 순서로 재서 처음으로 80% 이상인 방식 → `building_attr_chosen` 에 이유와 함께 |
| 기본 경로 | setup 기본 자료 폴더 `C:\Users\user\Desktop\박수범` (Enter = 기본값). 하위 폴더(`DEFAULT_SUBDIRS`)가 모두 알려져 있고 그대로면 질문 없이 확인 표만. 코드 폴더(hbi·hbi6·hbi_geopandas)는 훑지 않음 |
| hbi6 | v6 번들은 `hbi6/` 로 풀림 (안심구역의 v5 `hbi/` 는 그대로). hbi_geopandas 는 v6 번들에 넣지 않음 |
| 대소문자 | 파일·레이어 이름, CSV 머리 줄, 비교하는 값(용도 코드·계단 코드·07/10/11/14 의 filter·contains) 모두 대소문자 무시. setup 의 값 모양 검사도 |
