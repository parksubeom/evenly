# 기설치·예정 이동편의시설 목록

목록 파일: `data_public/existing_facilities.csv` (15곳, 열: name, gu, type, status, opened, lon, lat, length_m, rise_m, note, source, coord_precision, coord_source)

- 좌표는 출처에 나온 곳만 적었습니다. 모르는 곳은 빈 칸이며, 지어내지 않습니다.
- [10/12] 좌표를 다시 잡고 행마다 `coord_source` 에 출처를 적었습니다 (OSM 객체 번호 + 서울시·구청 글의 위치 표현, 봉천은 관악 실측 기록지와 같은 연속수치지형도 계단 양 끝의 가운데). `coord_precision`: 시설 9곳(시설 자체), 근사 3곳(옆 학교·공원·길 노드, 시설에서 200m 안), 없음 3곳(성동 대현산공원·금천 장미공원·강북 오동근린공원: 출처 있는 위치를 찾지 못했고 설치 여부도 미확인). 기획서 17장 '500m 안 기존 시설'은 status 가 existing 인 좌표 있는 곳만 셈 (OSM 자료는 ODbL).
- 다시 잡으며 찾은 것: 대현산배수지 모노레일의 예전 점은 하부가 아니라 둘째(중간) 승강장이었음(26m), 금호터널 옆 옹벽 엘리베이터는 OSM 에 없어 설치 여부 확인 필요, 개통 시기가 출처마다 다름(금동초 2022.02 / 금천구 보도자료 2023-02-27 개통식, 북아현 2023.01 / 내 손안에 서울 2023.02.14, 대현산배수지 2024.02.15 는 opened 칸이 빔) → opened 칸은 그대로 둠
- `status` 가 `existing(확인필요)` 인 곳은 운영 여부를 아직 확인하지 못했습니다. 출처가 빈 곳은 출처 확인이 필요합니다.
- type: elevator = 경사형 엘리베이터, monorail = 모노레일, vertical = 수직 엘리베이터(보행데크 포함)

## 이 목록을 어디에 쓰나

| 용도 | 방법 | 필요한 것 |
|---|---|---|
| 기설치 효과 사후 확인 | existing 시설을 `analysis/hbi/external/interventions.csv` 에 `status=existing` 으로 넣고 09_intervention.py 로 "그 시설이 없었다면" 과 비교 | 시설 양 끝 좌표 (현장실측·지도) |
| 선정지 예상 효과 | planned 5곳을 `status=planned` 로 넣어 수혜 건물 수·단축 분 계산 (기획서 22·23장) | 양 끝 좌표 (현장실측 기록지 ①③⑤ 등) |
| 사각지대 찾기 | HBI 가 높은데 반경 500m 안에 시설(existing·planned)이 하나도 없는 격자 = 우선 검토 대상 | 이 목록의 좌표 + 반출 grid_hbi.csv |

## 연혁

- 2018.11 용산구 후암동 108하늘계단에 서울 최초의 경사형 엘리베이터 (계단 53m)
- 2020.11 구릉지 이동편의 개선사업: 중구 대현산배수지공원 모노레일(110m) 등, 주민공모로 대상지 선정 (서울시 보도자료)

- 2025.06 고지대 이동편의시설 우선 설치대상지 5곳 선정 (숭인·신당·봉천·중곡·화곡), 2027 준공 목표 (내 손안에 서울 2025.06.13)
