# 기설치·예정 이동편의시설 목록

목록 파일: `data_public/existing_facilities.csv` (15곳, 열: name, gu, type, status, opened, lon, lat, length_m, rise_m, note, source)

- 좌표는 출처에 나온 곳만 적었습니다. 모르는 곳은 빈 칸이며, 지어내지 않습니다. 적힌 좌표도 대부분 "근사"(note 열 참고)입니다.
- `status` 가 `existing(확인필요)` 인 곳은 운영 여부를 아직 확인하지 못했습니다. 출처가 빈 곳은 출처 확인이 필요합니다.
- type: elevator = 경사형 엘리베이터, monorail = 모노레일, vertical = 수직 엘리베이터(보행데크 포함)

## 이 목록을 어디에 쓰나

| 용도 | 방법 | 필요한 것 |
|---|---|---|
| 기설치 효과 사후 확인 | existing 시설을 `analysis/hbi/external/interventions.csv` 에 `status=existing` 으로 넣고 09_intervention.py 로 "그 시설이 없었다면" 과 비교 | 시설 양 끝 좌표 (현장실측·지도) |
| 선정지 예상 효과 | planned 5곳을 `status=planned` 로 넣어 수혜 건물 수·단축 분 계산 (기획서 22·23장) | 양 끝 좌표 (현장실측 기록지 ①③⑤ 등) |
| 사각지대 찾기 | HBI 가 높은데 반경 500m 안에 시설(existing·planned)이 하나도 없는 격자 = 우선 검토 대상 | 이 목록의 좌표 + 반출 grid_hbi.csv |

## 연혁

- 2018.11 용산구 후암동 108하늘계단에 서울 최초의 경사형 엘리베이터 (계단 53m)
- 2020.11 구릉지 이동편의 개선사업: 중구 대현산배수지공원 모노레일(110m) 등, 주민공모로 대상지 선정 (서울시 보도자료)
- 2022 성동구 옥수교회 옆, 금천구 금동초교 수직 엘리베이터 (금동초는 보행데크 포함, 서울시 추산 수혜 약 5,500명)
- 2023.01 서대문구 북아현동 경사형 엘리베이터 준공 (이대역 접근, 경향신문 2023.01.28)
- 2025.06 고지대 이동편의시설 우선 설치대상지 5곳 선정 (숭인·신당·봉천·중곡·화곡), 2027 준공 목표 (내 손안에 서울 2025.06.13)
