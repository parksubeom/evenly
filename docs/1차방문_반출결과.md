## 범위: 받은 11도엽이 관악구만인 이유

`external/dong_boundary.geojson` 의 관악구 경계와 겹치는 1:5,000 도엽을 계산하면 **11장**이다 (맞닿기만 하는 37612006 제외).

`37612007 37612008 37612009 37612010 37612017 37612018 37612019 37612020 37612028 37612029 37612030`

받은 폴더 이름(11개) 앞 8자리가 이 목록과 같으면 센터가 관악구 경계로 잘라 준 것이다. 확인된 이름은 `37612008` 하나뿐이라 나머지는 대조가 필요하다.
- 같으면: 다른 구는 따로 요청해야 함 → `docs/범위요청_메일초안.md`
- 사용자가 고른 것이면: setup 의 폴더 자동 선택으로 해결 (v6 에 있음)

도엽 번호 계산 규칙: 1:50,000 도엽 = 위도 도(2자리) + 경도 일의 자리(1자리) + 1° 안 15′ 칸 4×4 의 번호(북서부터 가로로 01~16). 1:5,000 = 그 안 1.5′ 칸 10×10 의 번호(북서부터 가로로 001~100). 관악구로 계산한 장 수(11)가 받은 장 수와 같다.

## 넣지 않은 것

| 항목 | 이유 |
|---|---|
| 보도 면 → 길마다 "보도 있음 비율·평균 폭" (선택 항목) | 보도 면은 도로중심선에서 도로 폭 절반쯤 떨어져 있어, "이 길에 보도가 있다"고 볼 거리 기준(예: 10m)을 정해야 함. 기준을 정하면 경로 계산을 바꾸지 않고 02·05 에 붙일 수 있음 |
| HBI 구간 1.3·1.8 바꾸기 | 지시대로 그대로. 대신 summary·결과 점검표에 분위수(50·75·90·95·99%)와 왕복 추가 시간(분) 분위수를 냄 |

## 사용자 메모로 확정할 것

1. 건물 `용도` 값 형식: 코드(BDU001)인지, 한글 코드명(주거용단독주택)인지, 다른 이름(단독주택 등)인지. v6.1 은 앞의 둘을 받음. 다른 이름이면 check 가 "정의서 코드·코드명으로 읽히지 않은 용도 값 N채 (글자 모양 …)"로 알려 줌
2. `도로구분`·`자동차전용` 값 형식 (코드 / 한글 / Y·N). Y·N 이면 `mapping.txt` 의 `walk_exclude_mtrwy = Y`
3. DEM 5m·1m 폴더 이름, 상호제공 폴더 이름 → setup 의 `DEFAULT_SUBDIRS`
4. 받은 11도엽이 센터 제공 전부인지 (위 "범위")
